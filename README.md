# Using jQuery libraries to improve user experience, reducing site page count from 10 to 6. 

## Objective
The objective of this project was to identify pain points on an existing site and improve the user experience.

## Synopsis
This site belongs to a local small business that I frequent, and as an experienced user of the site, I noticed there were several sections that were confusing for new users. I am very committed to my community and I want to see small businesses thrive, this inspired me to offer my services to improve the site and try to reach more users.

## Process
I started by interviewing the client and getting a feel of what they wanted to communicate with their business. I created two different mood boards with color pallets and fonts for the client to choose from. I performed a heuristic evaluation on the existing site to identify pain points and grow opportunities. I created wireframes with the new site design, this design took into consideration both new and experienced users. I made a plan and identified what tools I would be using to improve the site usability. I started coding a prototype for the site in VS code. The prototype is still being worked on, next steps are to add styles and jQuery libraries.

## Results
The site is not finished yet, the prototype is being worked on in VS code, only some content was added, next step is to add styles and JS. The redesigned site will feature an easier flow for new users, as well as a simplified about us section, going from 5 pages of information to only 1. The project can be seen here:
